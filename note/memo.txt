Git     = 自分のPC上で変更履歴を管理する道具
GitHub  = Gitの履歴をネット上に置いて共有・バックアップする場所
commit  = ローカルの変更を「ここまでの作業」として記録すること
push    = ローカルのcommitをGitHubへアップロードすること
編集する
↓
git status で変更確認
↓
git add で「次のcommitに入れる変更」を選ぶ
↓
git commit でローカルに記録
↓
git push でGitHubに送る
